# 回归脚本通用化（2026-09-21）

## 一、需求

回归分析脚本不应该绑定在 EP 因子上：后续还要测试市净率、规模、ROE 等其它因子，
如果脚本名和输出列名都写死成 `ep`，每加一个因子就要复制一份代码，又会回到
「同一套口径多份实现」的老问题。

目标：脚本的功能是**读取一份因子数据，输出这份因子的回归统计结果**，换因子只换
参数、不改代码。

## 二、改动内容

### 2.1 脚本改名

| 原名 | 新名 |
|---|---|
| `代码/monthly_rlm_ep.py` | `代码/cross_section_rlm.py` |
| `代码/monthly_ols_ep_size.py` | `代码/cross_section_ols.py` |

### 2.2 增加命令行参数

| 参数 | 默认值 | 说明 |
|---|---|---|
| `--factor` | `ep` | 因子名或因子文件路径。因子名解析为 `因子结果/<名称>.parquet` |
| `--factor-name` | 取因子文件名 | 报告标题与配置里的因子标签 |
| `--out-root` | `回归结果/` | 结果根目录 |
| `--min-observations` | `500` | 单月最小观测数 |
| `--huber-t` | `1.345` | Huber 调优常数（仅 RLM） |

```powershell
python "代码\cross_section_rlm.py"                                       # 因子结果/ep.parquet
python "代码\cross_section_rlm.py" --factor pb                           # 因子结果/pb.parquet
python "代码\cross_section_rlm.py" --factor "D:/其它/my.parquet" --factor-name MY
```

### 2.3 输出目录改为按因子分目录

原来所有因子共用一个 `回归结果/RLM_H1_独立同方差/`，多个因子会互相覆盖。现在改为：

```
回归结果/
├── ep/
│   ├── RLM_H1_独立同方差/
│   └── OLS_月度/
├── size/
│   └── RLM_H1_独立同方差/
├── OLS_单日示例/               ← 历史学习记录，保留原位
└── _历史口径存档/OLS_日复合收益/  ← 已废弃的旧口径，保留备查
```

### 2.4 输出列名去掉因子前缀

| 原名（EP 专用） | 新名（通用） |
|---|---|
| `ep_beta` | `factor_beta` |
| `ep_bse` | `factor_bse` |
| `ep_zvalue` | `factor_zvalue` |
| `ep_pvalue` | `factor_pvalue` |

汇总表同理：`ep_mean` → `factor_mean`，`ep_iid_t` → `factor_iid_t` 等。
`size_*` 列名不变。这样下游（IC、分层回测、多因子对比）读任何因子都用同一套列名。

### 2.5 共享模块同步调整

- `common/panel.py`：`ep_z` → `factor_z`，`ep_valid` → `factor_valid`，审计表列名
  `n_valid_ep*` → `n_valid_factor*`；`prepare_formation_panel` 的第二个参数由
  `ep` 改为 `factor`。
- `common/paths.py`：新增 `resolve_factor_path()`，把「因子名 / 相对路径 / 绝对路径」
  统一解析为因子文件。
- 报告标题、图片文件名改为按因子生成，例如 `RLM统计结果.md` 标题为
  「EP 因子月度横截面 Huber RLM 统计结果」，图片为 `rlm_factor_premium.png`。

## 三、验证

### 3.1 EP 因子：改造前后数值完全一致

用同一个因子重跑，与改造前的输出逐项比较（列名按 2.4 对照后比较）：

| 输出 | 结果 |
|---|---|
| `rlm_monthly_results.csv` | 最大差异 **0.000e+00** |
| `rlm_annual_summary.csv` | 最大差异 **0.000e+00** |
| `rlm_overall_summary.csv` | 最大差异 **0.000e+00** |
| `rlm_sample_audit.csv` | 最大差异 **0.000e+00** |
| `forward_monthly_returns.parquet` | 319,074 行，最大差异 **0.000e+00** |

全期关键指标：64 个月，因子月均系数 0.1623%，IID t 值 1.4487，p 值 0.1524。
产物数量一致（15 个文件），唯一区别是图片由 `rlm_ep_premium.png` 改名为
`rlm_factor_premium.png`。

### 3.2 换因子：规模因子零改动跑通

直接用路径指向其它交付版的因子文件，代码一行未改：

```powershell
python "代码\cross_section_rlm.py" --factor "D:/因子计算/规模因子_交付版/因子结果/size.parquet"
```

结果输出到 `回归结果/size/RLM_H1_独立同方差/`，与 EP 的结果互不干扰：

| 因子 | 月份 | 月均系数 | IID t 值 | IID p 值 | 正系数比例 |
|---|---:|---:|---:|---:|---:|
| EP | 64 | +0.1623% | 1.4487 | 0.1524 | 53.13% |
| SIZE | 64 | −1.4782% | −3.8338 | 0.0003 | 28.13% |

规模因子在当前样本与模型下比 EP 显著得多，这个结果也说明脚本对换因子是真正可用的，
不是只在 EP 上能跑。

## 四、注意事项

因子文件格式必须与交付一致：`index = ['date', 'stock_code']`，
`columns = ['signal']`，且 `date` 需覆盖全部月末形成日，否则
`prepare_formation_panel` 会因找不到对应记录而直接报错。这是刻意的设计：
宁可报错，也不要静默丢样本。
